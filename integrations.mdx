## GitHub Integration

Connect your GitHub repositories to automatically sync documentation changes.

<Steps>
  <Step title="Install GitHub App" icon="download">
    Install the Work-ai GitHub App from the GitHub Marketplace.
  </Step>
  <Step title="Authorize Repository" icon="key">
    Grant access to the repositories you want to sync.
  </Step>
  <Step title="Configure Sync Settings" icon="settings">
    Set up automatic syncing and webhook triggers.
  </Step>
</Steps>

<CodeGroup tabs="Webhook Setup,API Sync">
  ````javascript
// Webhook configuration
const webhookConfig = {
  url: 'https://workai.com/webhooks/github',
  events: ['push', 'pull_request']
};
  ````
  ````python
from workai.integrations import GitHubIntegration

gh = GitHubIntegration(api_key='your-key')
gh.sync_repository('owner/repo')
  ````
</CodeGroup>

## Custom Integrations

Build your own integrations using Work-ai's REST API and webhooks.

<CodeGroup tabs="Webhook Handler,API Client">
  ````javascript
const express = require('express');
const app = express();

app.post('/webhook', (req, res) => {
  const { event, data } = req.body;
  // Handle webhook event
  res.sendStatus(200);
});
  ````
  ````python
import requests

class CustomIntegration:
    def __init__(self, api_key):
        self.api_key = api_key
    
    def create_document(self, title, content):
        response = requests.post(
            'https://api.workai.com/documents',
            headers={'Authorization': f'Bearer {self.api_key}'},
            json={'title': title, 'content': content}
        )
        return response.json()
  ````
</CodeGroup>

## Integration Best Practices

Follow these guidelines to ensure smooth integration with Work-ai.

| Best Practice | Description |
|---------------|-------------|
| Use Webhooks | Real-time updates without polling |
| Handle Errors | Implement proper error handling and retries |
| Rate Limiting | Respect API rate limits to avoid throttling |
| Secure Keys | Store API keys securely and rotate regularly |
