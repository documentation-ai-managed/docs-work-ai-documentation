## Basic Configuration

Configuring Work-ai is straightforward and can be done through our web interface or programmatically via the API. Start by setting up your project settings and user permissions.

<Steps>
  <Step title="Create Project" icon="folder">
    Begin by creating a new project in your Work-ai dashboard.
    
    <CodeGroup tabs="UI,API">
      ````bash
      # Via UI: Navigate to Projects > Create New
      ````
      ````javascript
const response = await fetch('/api/projects', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'My Project' })
});
      ````
    </CodeGroup>
  </Step>
  <Step title="Set Permissions" icon="shield">
    Configure user roles and access levels for your team members.
  </Step>
  <Step title="Customize Settings" icon="settings">
    Adjust theme, notifications, and other preferences.
  </Step>
</Steps>

## Environment Variables

Work-ai supports configuration through environment variables for deployment flexibility.

<CodeGroup tabs="Docker,Heroku">
  ````bash
# Docker environment
WORKAI_API_KEY=your-api-key
WORKAI_PROJECT_ID=your-project-id
WORKAI_DATABASE_URL=postgresql://localhost/workai
  ````
  ````bash
# Heroku config vars
heroku config:set WORKAI_API_KEY=your-api-key
heroku config:set WORKAI_PROJECT_ID=your-project-id
  ````
</CodeGroup>
