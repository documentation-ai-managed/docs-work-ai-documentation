## Automation

Automate repetitive tasks and workflows with Work-ai's powerful automation features.

<CodeGroup tabs="Workflow Script,API Automation">
  ````javascript
// Automate document publishing
const automation = {
  trigger: 'on-merge',
  actions: [
    { type: 'publish', target: 'website' },
    { type: 'notify', channel: 'slack' }
  ]
};
  ````
  ````python
from workai.automation import Workflow

workflow = Workflow()
workflow.add_trigger('document_updated')
workflow.add_action('generate_pdf')
workflow.add_action('send_email')
workflow.execute()
  ````
</CodeGroup>
