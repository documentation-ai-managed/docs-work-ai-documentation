## Getting Started

Work-ai is a powerful documentation platform designed to help teams organize, manage, and collaborate on project documentation efficiently. It provides an intuitive interface for creating, editing, and sharing documentation across your organization. Whether you're building technical docs, API references, or knowledge bases, Work-ai streamlines the process with advanced features and seamless integration options.

## Use Cases

Work-ai is versatile and can be adapted to various documentation needs across different industries.

<Callout kind="info">Whether you're documenting APIs, creating user guides, or maintaining internal knowledge bases, Work-ai provides the tools you need.</Callout>

<CodeGroup tabs="JavaScript,Python">
  ````javascript
  // Example: Initialize Work-ai client
const workai = new WorkaiClient({
  apiKey: 'your-api-key',
  projectId: 'your-project-id'
});
  ````
  ````python
from workai import WorkaiClient

client = WorkaiClient(
    api_key='your-api-key',
    project_id='your-project-id'
)
  ````
</CodeGroup>
